# Agent Factory v0.7.0 — Changelog

Based on the independent v0.6.0 adversarial execution audit.

## Fixed
- Removed duplicate `impersonated` / `impersonation` flat risk entries. All five impersonation forms now use one variant group.
- Added `@handle` detection for third-party payment claims.
- Prevented zero and negative extracted amounts from becoming payment records.
- Added `copywriting` / `copywriter` morphology to content capability detection.
- Added `automatedly` to automation morphology.
- Updated the scout banner, CLI description, and source User-Agent to v0.7.0.
- Added configuration integrity validation to catch future flat-list/variant-map duplication.

## Alignment
- Added USDT to the payment vocabulary and extraction path. This aligns the code with the cornerstone's initial stablecoin payment target.

## Verification
- Test suite: 43 passed, 0 failed.
- CLI smoke test: `init-db`, `scout`, and `report` completed successfully.
- Live Moltbook/MoltJobs access was unavailable in the test environment, so live API compatibility remains unverified.
- No wallet signing, spending, withdrawal, or blockchain verification was added.
